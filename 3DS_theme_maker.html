3DS Theme Editor — Web

ブラウザだけで動く Usagi 3DS Theme Editor の移植版（背景・アイコン・タイトル編集）

元プロジェクト ↗
移植範囲について： 元の C# / WPF 版はカラーパレット全種の個別編集やアニメーションプレビューなど非常に広範な機能を持つデスクトップアプリです。 ブラウザだけで完結させるため、この移植版は トップ/ボトム画面の背景画像・アプリアイコン・タイトル情報・BGM の編集 に絞っています。 既存テーマを開いた場合、それ以外のバイト列（個別カラー設定など）はファイルからそのまま保持されるので、見た目を壊さずに画像だけ差し替えられます。 圧縮は簡易的な無圧縮 LZ11 ストリームで書き出すため（3DS 本体は問題なく読み込めます）、出力ファイルは元よりやや大きくなります。 BGM の自動変換（方法B）は本家アプリの機能ですが、本家はこの部分を Windows 専用の非公開の変換ツール（配布物にソースコードが含まれない .exe）に丸投げしているため、移植元となるソースコードが存在しません。 当初は3dbrew.org の公式仕様書を元に PCM16 形式で自作していましたが、実際に動作するサンプルファイルをご提供いただいたところ、実機の BGM は DSP ADPCM という別の圧縮形式を使っていることが判明したため、既存の実績あるオープンソース実装（mu-wave の WebAssembly エンジン、内部は DspTool / libOgg / libVorbis）に切り替えました。詳しいライセンス表記は BGM セクション内にあります。

Background Music (BGM)

HOME メニュー表示中に流れる音楽（bgm.bcstm）。3DS はこの独自フォーマットの音声ファイルしか再生できません。

方法A（推奨）：.bcstm ファイルをそのまま使う 確実

すでにお持ちの .bcstm ファイルをアップロードします。中身は一切変更せずそのまま同梱するので、再生の確実性が最も高い方法です。

方法B：音声ファイルから自動変換（DSP ADPCM） 実績あり

wav / mp3 / ogg をブラウザ内で本物の 3DS BGM と同じ形式（DSP ADPCM、ループ対応）に変換します。mu-wave の変換エンジン（WebAssembly）をそのまま利用しており、独自の簡易実装ではありません。

同梱ライブラリのライセンス表記

変換エンジンは kazuki-4ys/mu-wave の WebAssembly ビルドをそのまま埋め込んでいます。内部で使われている DspTool（MIT License, Copyright (c) 2017 Alex Barney）、 libOgg / libVorbis（Copyright (c) Xiph.org Foundation, BSD系ライセンス）にそれぞれ帰属します。
