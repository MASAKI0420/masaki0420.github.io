3DS Theme Editor — Web

ブラウザだけで動く Usagi 3DS Theme Editor の移植版（背景・アイコン・タイトル編集）

元プロジェクト ↗
移植範囲について： 元の C# / WPF 版はカラーパレット全種の個別編集やアニメーションプレビューなど非常に広範な機能を持つデスクトップアプリです。 ブラウザだけで完結させるため、この移植版は トップ/ボトム画面の背景画像・アプリアイコン・タイトル情報・BGM の編集 に絞っています。 既存テーマを開いた場合、それ以外のバイト列（個別カラー設定など）はファイルからそのまま保持されるので、見た目を壊さずに画像だけ差し替えられます。 圧縮は簡易的な無圧縮 LZ11 ストリームで書き出すため（3DS 本体は問題なく読み込めます）、出力ファイルは元よりやや大きくなります。 BGM の自動変換（方法B）は独自実装のため実機での動作を完全には保証できません — 詳しくは BGM セクションの説明をご覧ください。

Background Music (BGM)

HOME メニュー表示中に流れる音楽（BGM.BCSTM）。3DS はこの独自フォーマットの音声ファイルしか再生できません。

方法A（推奨）：.bcstm ファイルをそのまま使う 確実

すでにお持ちの .bcstm ファイルをアップロードします。中身は一切変更せずそのまま同梱するので、再生の確実性が最も高い方法です。

方法B（実験的）：音声ファイルから自動変換 実験的

wav / mp3 などをブラウザ内で PCM16 の BCSTM に変換します（ループなし、独自実装のため 3DS 実機での動作を完全には保証できません）。可能であれば方法Aを優先してください。
