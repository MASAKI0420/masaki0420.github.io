1. はじめに

太鼓さん次郎形式（.tja）の譜面を、ブラウザだけで遊べるプレイヤーです。
譜面・SE・背景はすべて、お使いのブラウザ内（IndexedDB）に保存されます。サーバーへは送信されません。

  1. TJAplayer_34_14.html をブラウザ（Chrome / Edge などを推奨）で開く
  2. 曲を追加する（2章）
  3. 曲と難易度を選び、「ゲーム開始 (Space)」を押す
初回はキー入力かクリックのあとに音が有効になります。譜面データを入れたブラウザとは別のブラウザ・別のURLで開くと、保存済みの譜面は表示されません。

2. 譜面を追加する

追加の手順

  1. 左上「譜面管理」の 追加 (ZIP) をクリック
  2. 譜面ZIPを選択（複数選択できます）
  3. ジャンルを聞かれるので、数字で指定

ZIPの中身

  • .tja ファイル（必須）
  • 音声ファイル（.mp3 / .ogg / .wav）。TJAの WAVE: で指定した名前を優先して探し、見つからなければZIP内の音声を自動で使います
  • 背景の動画・画像（任意。TJAの BGMOVIE: / BGIMAGE: で指定されたものを優先）

文字コードは UTF-8 / Shift-JIS / EUC-JP / UTF-16 などを自動判定します。

ジャンル（1〜9）

番号ジャンル番号ジャンル
1J-POP6クラシック
2アニメ7ゲームミュージック
3キッズ8ナムコオリジナル
4ボーカロイド9創作譜面（初期値）
5バラエティ

複数ファイルを追加するとき：

  • 数字（1〜9）＝全曲に同じジャンルを付ける
  • 0 ＝曲ごとに指定する
  • 空欄／キャンセル＝TJAのGENRE記載から自動判定（判定できなければ9）

あとから変えるには、曲を選んで ジャンル変更 (1〜9) を押します。

選ぶ・探す・消す

  • 曲を検索…：曲名で絞り込み
  • ジャンル：すべて：ジャンルで絞り込み（切り替えると選択中の曲はリセットされます）
  • 保存済み譜面を選択：プルダウンから曲を選ぶ
  • 削除：選択中の曲を削除
  • PCへ保存：選択中の譜面ZIPをPCにダウンロード（バックアップ用）

難易度

曲を選ぶと「難易度を選択」が出ます（かんたん / ふつう / むずかしい / おに / エディット。☆の数も表示）。
2P譜面（#START P2）は読み込みません。

3. 遊び方

キー操作（初期値）

操作キー
ドン（左 / 右）D / K
カッ（左 / 右）S / L
ポーズW または Esc
リトライR
メニューへ戻るH
ゲーム開始Space
  • 「キー設定」の枠をクリック → 割り当てたいキーを押すと変更できます（Escでキャンセル。他の操作と重複するキーは使えません）。
  • リトライ・メニューのショートカットは、画面右側「ショートカットキー」で変更できます（リトライは連続使用防止のため3秒のクールダウンあり）。
初回は枠の表示（X / Z など）が実際の割り当てとずれて見える場合があります。各枠を一度クリックして設定し直すと確実です。

音符

  • ドン（赤）：ドンキー ／ カッ（青）：カッキー
  • 大音符：「大音符を片手で処理」がONなら、どれか1キーで判定されます
  • 連打（黄色い帯）：期間中、ドン・カッのどちらでも連打
  • 風船：ドンで規定回数を叩いて割る
  • 譜面分岐（普通 / 玄人 / 達人）に対応しており、分岐は演奏成績で自動的に切り替わります

判定とスコア

  • 良 / 可 / 不可 の3段階。判定幅は難易度ごとに変わります
  • 配点はニジイロVer.方式（天井スコアがおよそ100万点）
  • 画面上のゲージが各難易度のノルマ線を超えると CLEAR。最後までミス無しなら FULLCOMBO、全て良なら ALLPERFECT

ポーズ・結果画面

  • ポーズ中は ↑↓ でボタンを選び、Enter で決定（再開 / やり直し / タイトルへ戻る）
  • 結果画面でも ↑↓ と Enter で、やり直しとタイトルを選べます

4. 設定一覧

表示・速度

  • スクロール速度：音符の流れる速さ（曲のBPMに応じて自動調整。譜面ごとに保存）
  • レーン不透明度／背景の明るさ
  • レーンカバー：右側の見える範囲を隠して、音符の見える範囲を狭める

オフセット（ms）

項目内容
譜面オフセットすべての譜面に共通のタイミング調整
個別譜面オフセットその譜面だけの調整（譜面ごとに保存）
動画オフセット背景動画だけをずらす（譜面ごとに保存）
SEオフセット叩いた音の鳴るタイミングだけ調整。音が遅れて聞こえる場合は -50 のようにマイナスを入力

プレイアシスト

  • オートプレイ：自動で演奏
  • 大音符を片手で処理：大音符を1キーで判定
  • 自動SE：音符のタイミングで自動的にSEを鳴らす

演奏オプション

  • ミスしたとき
    • そのまま
    • かんぺき：不可で演奏終了
    • 超かんぺき：可・不可で演奏終了
    • とっくん：不可でやり直し
    • 超とっくん：可・不可でやり直し
  • 音符の入れ替え：なし / きまぐれ（ちょっと） / でたらめ（かなり） / あべこべ（ドンとカッを逆に）
  • ドロン：音符を隠します（判定は通常どおり）
  • 演奏スキップ：プレイ中に Enter で演奏を終了して結果画面へ

サウンド

  • 曲の音量／SEの音量
  • SE（ドン・カッ）：自分のSEに差し替えられます
    1. 「追加 (ZIP)」で、dong.wav（ドン）と ka.wav（カッ）を入れたZIPを選ぶ
    2. 名前を付けて保存
    3. プルダウンから選んで使用（「名前変更」「削除」も可）
    ファイル名は don / katsu でも可。拡張子は wav / mp3 / ogg / m4a / flac / aac / opus が使えます

背景（動画・画像）

  • 背景（動画・画像）：ZIP内の背景を「動画」「画像」「背景なし」から選択
  • 背景を追加：動画・画像に名前を付けて保存（複数選択可）
  • 保存した背景を選択：保存した背景を選ぶと、その譜面用として記憶されます
  • 名前を変更 ／ 解除（標準に戻す）
  • ランダム ON/OFF：ONにすると、保存した画像の中から譜面を読み込んだとき・ゲーム開始時にランダムで選びます

5. 困ったとき

症状対処
音が出ない一度クリックかキー入力をしてから、もう一度開始してください
「ZIP内に音声ファイルが見つかりません」ZIPに .mp3 / .ogg / .wav が入っているか確認してください
「.tjaファイルが見つかりませんでした」ZIPの中に .tja があるか確認してください
音と譜面がずれる「譜面オフセット」または「個別譜面オフセット」で調整。SEだけなら「SEオフセット」
動画が読み込めない自動で画像に切り替わります。ブラウザが対応する形式（mp4 / webm など）をお使いください
保存できないブラウザの保存容量が上限の可能性があります。不要な譜面・背景を削除してください
「別のタブで開かれています」と出る他のタブやウィンドウを閉じてから再読み込みしてください（保存データは消えていません）
データが消えたブラウザのサイトデータを削除すると保存した譜面も消えます。大切な譜面は「PCへ保存」でバックアップしてください

6. 補足

  • ポーズ・リトライ・メニュー用のショートカットキー設定は、このプレイヤー全体の共通設定として保存されます
  • スクロール速度・個別オフセット・動画オフセット・選んだ背景は、譜面ごとに記憶されます
  • Esc キー長押しでフルスクリーンを解除できます
